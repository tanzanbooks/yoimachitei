# 法案をGitで読む

法案を読み、論点を書き、変更履歴をたどるための資料です。
公式の法律案を読みやすいMarkdownに変換しています。

## まず読む

1. [法案一覧](INDEX.md)を開きます。
2. 気になる法案の「提出時法律案」をクリックします。
3. 本文冒頭の出典リンクから、公式の原文も確認できます。
4. [検討メモ](notes/discussion.md)に感想や論点を書きます。

法律案は成立済みの法律とは異なります。掲載されているからといって、現在審議中とは限りません。
収録対象は衆議院の最新掲載回次の一覧に載る衆法・参法・閣法です。
予算・条約・決議は収録していません。衆議院掲載前の参議院案件など、両院すべての案件を網羅するものではありません。
取得回次・件数・警告は [取得記録](FETCH_LOG.md)で確認できます。

## Gitの楽しみ方：検討メモを育てる

Gitは変更履歴を保存する仕組み、GitHubはコードや文章を共有する場所です。
まずはGitHubの画面だけで試せます。

1. `notes/discussion.md` を開き、鉛筆の編集ボタンを押します。
2. 気になった法案と「どこが論点か」を1つ書き足します。
3. 保存時の説明に「○○法案の論点を追加」と書き、コミットします。
4. ファイルの履歴（History）を開いて、そのコミットをクリックします。
5. 赤い行が削除、緑の行が追加です。「議論のどこが進んだか」を読めます。

最初のアップロードだけでは比較対象がありません。2回目以降の編集で差分が見られます。
編集するには各自のGitHubアカウントと、リポジトリへの書き込み権限が必要です。
共通のパスワードを共有せず、それぞれのアカウントを使います。

## 修正案を試す

公式資料を直接書き換えず、`notes/` に「私案」と明記したファイルを作りましょう。
慣れたら別ブランチで私案を書き、Pull Requestで提案します。
条文ごとの変更と理由を並べて相談する、宵待亭の小さな法案検討会にできます。
このセットの履歴は私たちの取得・編集履歴です。国会での実際の修正過程を復元した履歴ではありません。

## 資料を更新する（tanzanbooks向け）

Python 3の標準ライブラリだけで実行できます。

```bash
python scripts/update_bills.py
```

公式の最新掲載一覧から本文・要綱・修正案を取得します。
修正案は公式ページに掲載され、抽出できた資料だけが対象です。
PDF資料は公式リンクで閲覧します。通信・書式変更による未取得は取得記録に表示します。
取得に失敗した既存ファイルは削除しないため、必ず最新の一覧と取得記録を確認してください。

更新後は内容を確認してコミットします。スクリプトは自動コミット・自動公開を行いません。

```bash
git diff --stat
git diff
git add INDEX.md FETCH_LOG.md data bills
git commit -m "公式の法案資料と審議状況を更新"
git push
```

最新回次が切り替わると一覧も切り替わります。以前の資料は保存されますが、新回次では更新されません。
前の一覧はGitの履歴から参照できます。
公式HTMLの変換では表の列配置・字下げ・傍線などの書式が失われます。正確な条文構造は原文で確認してください。

## GitHubへのアップロード

ZIPを展開して、`yoimachitei-bills` フォルダごと既存の `tanzanbooks/yoimachitei` に追加できます。
その中の `README.md` がこの説明です。ホームページ側のファイルを上書きする必要はありません。
ファイル数が多い場合は、一度リポジトリをパソコンへcloneし、フォルダをコピーしてGitでまとめて追加してください。

公開リポジトリでは、検討メモも誰でも読めます。内部の連絡事項は書かないようにしてください。
